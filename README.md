# TestLens MCP

TestLens is a read-only local MCP server for helping coding agents understand
JUnit-compatible test reports, including reports generated by pytest's
`--junitxml` option. It exposes report summaries and failure details without
running commands, changing files, or making network requests.

The project is motivated by two developer-workflow trends: MCP provides a
standard way to connect AI applications to tools, while developer survey
results show that generated output still needs independent verification.
Sources:

- [Model Context Protocol introduction](https://modelcontextprotocol.io/introduction)
- [Stack Overflow Developer Survey 2025: AI](https://survey.stackoverflow.co/2025/ai)

## Status

Early development. The CLI and report parser are being implemented first;
MCP support will be an optional extra.
